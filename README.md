## Overview

Bright TV is a data analytics project focused on analysing and improving television viewership patterns using structured data insights.

---

## Objective

* Increase viewership through data-driven content strategies
* Improve audience engagement and retention
* Enhance accuracy of viewership tracking and reporting systems

---

## Key Features

* Viewership trend analysis (hourly, daily, weekly)
* Audience demographic segmentation
* Peak viewing time identification
* Content performance tracking

---

## Data Sources

* TV broadcast logs
* Viewer demographic datasets
* Time-based consumption patterns
* Program and channel metadata

---

## Tech Stack

* SQL (BigQuery / Databricks)
* Data Visualization (Looker Studio)
* GitHub (Version Control)
* CSV / Excel datasets

---

## Project Structure

```
/data      → Raw & processed datasets
/sql       → Query scripts
/reports   → Insights & dashboards
/docs      → Documentation
```

---

## Key Metrics

* Total viewers per time interval
* Audience distribution by demographics
* Peak viewing hours and days
* Engagement rate per program

---

## How to Use

1. Import datasets into SQL environment
2. Run analysis scripts in `/sql`
3. Visualize results using BI tools
4. Generate insights for reporting

---

## Future Improvements
